# **App Name**: Devora

## Core Features:

- Zen Presence Hero: An AI-powered tool that generates daily meditative sumi-e ink art and growth-focused quotes tailored to the user's recent productivity trends.
- Cloud Project Core: A robust task and project architecture for organizing developments and milestones with real-time Firestore persistence.
- Deep Focus Meditation Timer: A zen-themed countdown widget with soft gradients and botanical visuals to facilitate periods of deep work and mental flow.
- Editorial Milestone Timeline: A vertical visual journal for project progress, displaying key dates and accomplishments in a high-contrast serif typography.
- Collective Pulse Feed: A minimalist olive-toned activity stream providing high-level team updates and recent contributions without cluttering the main interface.
- Priority Pulse Discovery: A smart filtering tool within the hero section to immediately surface the day's highest-leverage developer priorities.

## Style Guidelines:

- Primary: Muted Olive (#48644A) for navigation and presence indicators. Background: Warm Ivory (#F8F6F2) for a calm, editorial feel. Accent: Terracotta (#D46F4D) for high-impact interactions.
- Headlines use 'Playfair' for an elegant, high-contrast serif look, paired with 'Inter' as the body and UI font for geometric clarity.
- A generous 24px outer margin surrounding 28px large-radius floating cards to create a 'Muji-like' airy atmosphere.
- Single-stroke, lightweight outline icons that prioritize negative space over decorative complexity.
- Smooth, organic fade-ins and subtle y-axis translates to evoke the feeling of paging through a luxury design magazine.
